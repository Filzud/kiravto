   провайдеров. С ключом запишу настоящие.

**Про источник**
- Данные идут из внутреннего JSON: `POST /-/ajax/desktop-search/listing/` (`dealer_id=20866489`, `page_size`
  не больше 50) и `POST /-/ajax/desktop-search/getOfferCard/` (`offer_id=<id>-<hash>`).
  Параметр `dealer_code` API **молча игнорирует** — без `dealer_id` приходит вся база (651 291 машина).
- Фильтры по умолчанию прячут машины без фото. 20.10: сайт показывал 428, без фильтров — 453.
  В вашем ТЗ 397 — это, видимо, тоже счётчик с фильтрами и на другое время.
- Обычный HTTP-клиент получает `NEED_AUTH` или редирект на `auth.auto.ru`; браузер со своей сессией — нет.
  Если Авто.ру начнёт требовать вход и у браузера, честного обхода нет. Сервис пометит прогоны неполными
  и через два подряд напишет в админ-чат. Дальше я бы: снизил частоту, поставил резидентный IP в РФ и
  запросил у Авто.ру партнёрский/дилерский фид. Вход под чужим аккаунтом — нет.
- **Выдача отстаёт от карточек:** снятое объявление (`REMOVED`, без цены) ещё висит в списке. Из-за этого упал
  живой прогон №1, теперь обрабатывается.
