# Отчёт «Жду / Сделано / Нашёл»

Подходит для любого проекта: три блока, цифры, честность.

## Как собрать цифры (этот проект)
```bash
python -m kiravto status          # последние прогоны: собрано/заявлено, запросы, ошибки, блокировки, время
python -m pytest -q               # сколько тестов, все ли зелёные
```
Или MCP: `get_runs_status`, `get_stock_summary`.

## Формат
```
### Жду от вас
- конкретное действие человека и зачем (или «ничего»)
### Сделано
- пункт — цифра — как проверено (тест X, живой прогон #N, сверка 20 объявлений)
### Нашёл
- факты об источнике, баги, риски
- неподтверждённое — с пометкой «не проверено» и как проверить
```

## Правила
- «Жду от вас» всегда первым, даже если пусто.
- Каждый пункт «Сделано» — с цифрой и способом проверки. Нет проверки → пункт идёт в «Нашёл» как «не проверено».
- Не округляй в лучшую сторону: «собрано 449 из 453», а не «собрано всё».
- Ошибки агента, пойманные по ходу, — в «Нашёл» (это ценно, не прячь).
