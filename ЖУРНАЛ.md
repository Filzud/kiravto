## 01:15 — Stop-хук сработал на деле и нашёл баг кодировки
Проверка хуков через `claude -p` в корне проекта (модель haiku): попросили прочитать `.env`.
1. Claude Code сам указал на ошибку в `settings.json`: правило `Write(./.env)` не работает, только `Edit(...)`.
   Исправлено.
2. При завершении той сессии **Stop-хук `tests_green.py` заблокировал её**: тесты хуков падали.
   Причина — без `PYTHONIOENCODING=utf-8` `guard.py` пишет причину отказа в cp1251, а Claude Code и тест
   читают UTF-8. У основного агента переменная всегда была выставлена, поэтому баг не был виден.
   Исправлено в самих хуках (`reconfigure(encoding="utf-8")`), набор прогнан без переменной: 120 passed.
